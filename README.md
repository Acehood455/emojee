# Emojee Explorer

A vanilla JavaScript emoji search project that fetches emoji data from the provided external source and displays it in a responsive card layout.

## Features

- Fetches emoji data from `https://akhil-06.github.io/emoji_project/emojiList.js`
- Displays the full emoji collection on page load
- Live search by description, alias, tag, and category
- Category filter chips
- Copy-to-clipboard interaction for each emoji
- Responsive UI for desktop and mobile

## Files

- `index.html`
- `styles.css`
- `script.js`

## Run locally

Open `index.html` in a browser with internet access.

## Deploy on GitHub Pages

1. Push these files to a GitHub repository.
2. Open the repository `Settings`.
3. Go to `Pages`.
4. Set the source to the main branch root folder.
5. Save and use the generated GitHub Pages URL as your hosted link.
